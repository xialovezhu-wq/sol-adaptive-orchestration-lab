# 多代理编排实验室

用于研究任务分工、只读子代理角色与窄范围检索的多代理编排实验配置及合成样例。

这是 2026-08-23 的可复现配置快照，包含角色定义、任务范围约束、窄范围字段提取和多文件检索的纯合成材料。它没有后台常驻模型，也不包含真实任务会话。

## 结构

- `.codex/agents/`：历史实验角色配置。
- `.codex/config.toml`：项目级配置。
- `.agents/skills/`：实验用技能合同。
- `fixtures/`：人工构造的测试文本和预期结果。

## 使用

将该目录作为独立实验项目，先检查本机客户端是否支持配置中的模型和角色字段，再按自己的授权范围发起只读实验。这里的模型名与档位属于历史实验配置，不证明当前可用；不应直接覆盖全局配置。

本次只发布配置与样例，没有发起新的模型评测或宣称历史实验通过。
